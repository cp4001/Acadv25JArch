제공해주신 DreamPlus의 레이어 관련 명령어 목록 전체를 그룹별로 나누어 간단한 설명과 사용법(명령어)으로 정리했습니다.

1. 레이어 변경 및 일치
객체의 레이어를 변경하거나 현재 레이어를 설정합니다.

자주 사용하는 객체 레이어 변경 (FML)

설명: 미리 지정한 8개의 레이어 중 하나로 객체의 레이어를 빠르게 변경합니다.

사용법: FML 입력 후, 대화상자에서 원하는 레이어를 선택(하거나 숫자 1~8 입력)하고 객체를 선택합니다.

레이어 일치 (LMA)

설명: AutoCAD의 LAYMCH와 동일. 한 객체의 레이어를 다른 객체의 레이어와 동일하게 변경합니다.

사용법: LMA 입력 후, 변경할 객체(들)를 먼저 선택하고, 기준이 될 객체를 선택합니다.

현재 레이어로 설정 (SCL)

설명: AutoCAD의 LAYMCUR와 동일. 선택한 객체의 레이어를 현재 작업 레이어로 설정합니다.

사용법: SCL 입력 후, 원하는 레이어의 객체를 선택합니다.

현재 레이어로 변경 (CCL)

설명: 선택한 객체(들)를 현재 작업 중인 레이어로 변경합니다.

사용법: CCL 입력 후, 변경할 객체(들)를 선택합니다.

현재 레이어로 복사 (CTL)

설명: 객체를 복사하되, 복사본을 현재 작업 레이어로 생성합니다.

사용법: CTL 입력 후, 복사할 객체(들)를 선택하고 기준점과 대상점을 지정합니다.

다른 레이어로 복사 (CEL)

설명: 선택한 객체를 다른 레이어로 복사합니다.

사용법: CEL 입력 후, 객체를 선택하고 대화상자에서 대상 레이어를 선택합니다.

다른 레이어로 변경 (MEO)

설명: 선택한 객체를 다른 레이어로 이동(변경)시킵니다.

사용법: MEO 입력 후, 객체를 선택하고 대화상자에서 대상 레이어를 선택합니다.

새 레이어로 변경 (MEL)

설명: 새 레이어를 만들면서 선택한 객체를 그 레이어로 즉시 변경합니다.

사용법: MEL 입력 후, 객체를 선택하고 대화상자에서 새 레이어 이름을 입력합니다.

2. 레이어 켜기 / 끄기 (On / Off)
레이어의 가시성을 제어합니다.

레이어 끄기 (LOF)

설명: 선택한 객체의 레이어를 끕니다. (AutoCAD의 LAYOFF)

사용법: LOF 입력 후, 끌 객체를 선택합니다.

모든 레이어 켜기 (LON)

설명: 꺼지거나(Off) 동결된(Freeze) 모든 레이어를 한 번에 켭니다.

사용법: LON 입력

선택한 레이어만 켜기 (LOL)

설명: 선택한 객체의 레이어만 켜고 나머지는 모두 끕니다. (AutoCAD의 LAYISO)

사용법: LOL 입력 후, 켜둘 객체를 선택합니다.

동결된 레이어만 켜기 (FLO)

설명: 현재 동결(Freeze) 상태인 레이어만 켭니다. (꺼진 레이어는 그대로 둠)

사용법: FLO 입력

동결, 꺼진 레이어만 켜기 (FOO)

설명: 동결(Freeze)되었거나 꺼진(Off) 상태의 레이어만 골라서 켭니다.

사용법: FOO 입력

꺼진 레이어만 켜기 (OLO)

설명: 현재 꺼진(Off) 상태인 레이어만 켭니다. (동결된 레이어는 그대로 둠)

사용법: OLO 입력

레이어 끄기 상태 백업, 복원 (LBR)

설명: 현재 레이어의 켜기/끄기 상태를 저장(백업)했다가 나중에 다시 복원합니다.

사용법: LBR 입력 후 '백업' 또는 '복원' 옵션 선택

3. 레이어 동결 / 해제 (Freeze / Thaw)
레이어를 도면에서 완전히 동결시키거나 해제합니다.

레이어 동결 (LFR)

설명: 선택한 객체의 레이어를 동결시킵니다. (AutoCAD의 LAYFRZ)

사용법: LFR 입력 후, 동결할 객체를 선택합니다.

선택 레이어외 모두 동결 (FRE)

설명: 선택한 객체의 레이어만 남기고 나머지 모든 레이어를 동결시킵니다. (AutoCAD의 LAYISO 동결 옵션)

사용법: FRE 입력 후, 남길 객체를 선택합니다.

모든 레이어 동결해제 (LTH)

설명: 동결된 모든 레이어를 해제합니다. (AutoCAD의 LAYTHW)

사용법: LTH 입력

선택 레이어를 뷰포트에서 VP 동결 (VPFV)

설명: 현재 활성화된 배치(Layout) 뷰포트에서 선택한 객체의 레이어를 'VP 동결'시킵니다.

사용법: VPFV 입력 후, 뷰포트 안에서 객체를 선택합니다.

선택 레이어를 지정 배치에서 VP 동결 (VPFL)

설명: 특정 배치(Layout) 탭을 지정하여, 선택한 객체의 레이어를 해당 배치의 모든 뷰포트에서 'VP 동결'시킵니다.

사용법: VPFL 입력 후, 객체 선택 및 배치 탭 지정

4. 레이어 잠금 / 해제 (Lock / Unlock)
레이어를 편집 불가능하도록 잠그거나 해제합니다.

레이어 잠금 (LLO)

설명: 선택한 객체의 레이어를 잠급니다. (AutoCAD의 LAYLCK)

사용법: LLO 입력 후, 잠글 객체를 선택합니다.

모든 레이어 잠금 (ALO)

설명: 현재 도면의 모든 레이어를 잠급니다.

사용법: ALO 입력

선택 레이어외 모두 잠금 (LOE)

설명: 선택한 객체의 레이어만 제외하고 나머지 모든 레이어를 잠급니다.

사용법: LOE 입력 후, 잠그지 않을 객체를 선택합니다.

선택 레이어 잠금 해제 (LUL)

설명: 선택한 객체의 레이어 잠금을 해제합니다. (AutoCAD의 LAYULK)

사용법: LUL 입력 후, 잠금 해제할 객체를 선택합니다.

모든 레이어 잠금 해제 (ULA)

설명: 잠겨있는 모든 레이어를 한 번에 해제합니다.

사용법: ULA 입력

5. 레이어 플롯 (Plot) 설정
레이어의 출력 여부를 설정합니다.

선택 레이어 플롯 안됨 (LPF)

설명: 선택한 객체의 레이어를 '플롯 안 함'(출력 안 됨)으로 설정합니다.

사용법: LPF 입력 후, 출력하지 않을 객체를 선택합니다.

선택 레이어 플롯 가능 (LPO)

설명: 선택한 객체의 레이어를 '플롯 가능'(출력 함)으로 설정합니다.

사용법: LPO 입력 후, 출력할 객체를 선택합니다.

6. 외부 참조 (Xref) 레이어
외부 참조(Xref) 도면의 레이어를 제어합니다.

선택한 외부참조 레이어 끄기 (XLOF)

설명: 외부 참조 도면의 객체를 선택하여 해당 레이어를 끕니다.

사용법: XLOF 입력 후, 외부 참조 객체 선택

외부참조 레이어 켜기 (XLON)

설명: 꺼져 있는 모든 외부 참조 레이어를 켭니다.

사용법: XLON 입력

외부참조 색상 변경 (XFC)

설명: 외부 참조 도면 전체의 색상을 특정 색(예: 회색)으로 일괄 변경합니다.

사용법: XFC 입력 후, 대화상자에서 색상 지정 및 외부 참조 선택

외부참조 레이어 상태 복원 (RXL)

설명: 변경된 외부 참조 레이어의 상태(색상, 켜기/끄기 등)를 원본 파일의 상태로 되돌립니다.

사용법: RXL 입력

7. 레이어 관리 및 도구
레이어를 만들거나, 삭제, 병합, 정리하는 등의 작업을 합니다.

레이어별 보기 (LWLK)

설명: 대화상자에서 원하는 레이어만 체크하여 화면에 표시하고 나머지는 모두 끕니다.

사용법: LWLK 입력 후, 대화상자에서 표시할 레이어 선택

레이어 만들기 (MLAY)

설명: 여러 개의 레이어를 한 번에 생성합니다. (이름, 색상, 선종류 등 지정 가능)

사용법: MLAY 입력 후, 대화상자에서 레이어 정보 입력

레이어 목록 도면에 작성 (LALI)

설명: 현재 도면의 레이어 목록(이름, 색상, 상태 등)을 표(테이블) 형태로 도면에 그립니다.

사용법: LALI 입력 후, 표 스타일 설정 및 삽입점 지정

객체 레이어 이름 쓰기 (WELN)

설명: 객체를 선택하면 해당 객체의 레이어 이름을 문자(Text)로 근처에 써줍니다.

사용법: WELN 입력 후, 객체 선택

레이어 필터 삭제 (DLF)

설명: 도면에 저장된 불필요한 레이어 필터를 삭제합니다.

사용법: DLF 입력

동결, 꺼진 레이어 객체 삭제 (DFO)

설명: 현재 동결(Freeze)되어 있거나 꺼져(Off) 있는 레이어의 모든 객체를 삭제합니다.

사용법: DFO 입력

객체 색상별 레이어 정리 (LC)

설명: 객체의 색상(Color)을 기준으로 각각 다른 레이어로 자동 분리/정리합니다.

사용법: LC 입력 후, 옵션 설정 및 객체 선택

레이어 객체 파일로 저장 (MLTF)

설명: 각 레이어에 속한 객체들을 별개의 DWG 파일로 분리하여 저장합니다.

사용법: MLTF 입력 후, 대화상자에서 저장 옵션 설정

지정 레이어 일괄 삭제 (MDLA)

설명: 여러 도면 파일을 열지 않고, 특정 이름의 레이어를 해당 도면들에서 일괄 삭제합니다.

사용법: MDLA 입력 후, 대화상자에서 도면 파일과 삭제할 레이어 이름 지정

레이어 병합 (LME)

설명: 여러 레이어를 하나의 대상 레이어로 합칩니다. (AutoCAD의 LAYMRG)

사용법: LME 입력 후, 병합할 객체(들)를 선택하고 대상 객체를 선택합니다.

8. 레이어 특성 변경
레이어의 이름, 색상 등 특성을 변경합니다.

레이어 특성 변경 (LP)

설명: 선택한 객체의 레이어 특성(색상, 선종류, 선가중치 등)을 변경합니다.

사용법: LP 입력 후, 대화상자에서 변경할 특성 지정 및 객체 선택

특정 레이어 특성 일괄 수정 (MOLP)

설명: 여러 도면 파일을 열지 않고, 특정 레이어의 특성(색상, 켜기/끄기 등)을 일괄 변경합니다.

사용법: MOLP 입력 후, 대화상자에서 도면 파일과 변경할 레이어 특성 지정

레이어 상태 일괄 적용 (MLS)

설명: 현재 도면의 레이어 상태(켜기, 끄기, 색상 등)를 다른 도면 파일들에도 동일하게 적용합니다.

사용법: MLS 입력 후, 대화상자에서 기준 도면과 대상 도면 설정

레이어 색상 변경 (LLP)

설명: 레이어의 색상을 변경합니다.

사용법: LLP 입력 후, 대화상자에서 레이어와 변경할 색상 선택

레이어 VP 색상 변경 (VLP)

설명: 현재 뷰포트(VP)에서만 레이어의 색상을 다르게 변경합니다.

사용법: VLP 입력 후, 대화상자에서 레이어와 변경할 VP 색상 선택

레이어 이름 일괄 변환 (CLN)

설명: 여러 레이어의 이름을 한 번에 찾아 바꾸거나(예: 'ABC' -> 'DEF'), 공통된 특성을 일괄 변경합니다.

사용법: CLN 입력 후, 대화상자에서 변경 전/후 이름 및 옵션 설정

레이어 이름 변경 (REL)

설명: 레이어 이름에 머리말/꼬리말 추가, 문자열 삭제 등 CLN보다 세부적인 규칙으로 이름을 일괄 변경합니다.

사용법: REL 입력 후, 대화상자에서 규칙 설정

9. 블록 및 기타 레이어 관련
블록이나 다른 객체와 연관된 레이어 작업입니다.

블록을 레이어로 폭파 (EEL)

설명: 블록을 분해(Explode)하면서, 블록 내부 객체들을 해당 블록이 속해 있던 레이어로 변경합니다.

사용법: EEL 입력 후, 분해할 블록 선택

블록 레이어, 색상 변경 및 교체 (RBC)

설명: 블록의 레이어, 색상 등을 변경하거나 다른 블록으로 교체합니다.

사용법: RBC 입력 후, 대화상자에서 옵션 설정 및 블록 선택

블록과 내부객체 레이어 맞춤 (MABL)

설명: 블록 내부 객체들의 레이어를 해당 블록 자체의 레이어와 동일하게 맞춥니다.

사용법: MABL 입력 후, 블록 선택

레이어별 Draworder (DRLA)

설명: 레이어 목록의 순서대로 객체들의 그리기 순서(앞/뒤 배치)를 정렬합니다.

사용법: DRLA 입력 후, 대화상자에서 레이어 순서 지정

레이어로 Offset (OTL)

설명: 객체를 간격띄우기(Offset) 하면서, 생성된 객체를 현재 레이어가 아닌 원본 객체의 레이어로 생성합니다. Example: OTL 입력 후 일반 Offset처럼 사용
