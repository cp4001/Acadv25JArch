# Duct_tag 명령어

> 파일: `PipeDiaCalc/DuctTagCommand.cs`
> 클래스: `PipeLoad2.DuctTagCommand.Cmd_DuctTag`
> 최종 업데이트: 2026-10-29 (신규, F-005)

---

## 1. 개요

XData `Tree` 덕트 Line 을 고르고 태그 위치를 찍으면 **Line 위 빨간 점에서 지시선을 그어 덕트 사이즈 `"{a}x{b}"` Text** 를 놓는다. Esc 까지 반복. [[InsertDuctSize]] 가 Line 중앙에 일괄로 넣는 것과 달리, 원하는 Line 에 원하는 위치로 하나씩 단다.

| 단계 | 동작 |
|---|---|
| ① | `태그할 덕트 Line 선택 (Esc 종료):` — `GetEntity`(Line 만). XData `Tree` 없으면 메시지 후 다시 선택 |
| ② | XData `a`, `b` 읽기. 없거나 `a` 가 양수가 아니면 메시지 후 다시 선택 |
| ③ | `태그 위치 지정:` — `GetPoint` |
| ④ | 점 = 클릭점을 Line 선분에 투영한 점. 수평/수직 판정 후 지시선 생성 |
| ⑤ | 지시선 Line + 점 + Text 생성 → ①로 돌아감 |

---

## 2. 형상

| Line 방향 | 지시선 | 글자 |
|---|---|---|
| 수평 (`abs(dx) >= abs(dy)`) | 점 → 클릭 높이까지 수직선 → 오른쪽으로 길이 h 수평선 | 수평선 끝 오른쪽, 왼쪽 정렬 |
| 수직 | 점 → 클릭 X 까지 수평 직선 | 클릭한 쪽 (오른쪽이면 왼쪽 정렬, 왼쪽이면 오른쪽 정렬) |

| 항목 | 값 |
|---|---|
| 글자 | `"{a}x{b}"` (XData 문자열 그대로) |
| 글자 높이 h | **`a`** ([[InsertDuctSize]] 는 a/2) |
| 글자 색 | ByLayer, 현재 문자 스타일 |
| 지시선·점 색 | ACI 1 (Red) |
| 점 | 채워진 원 — DONUT 방식 닫힌 2-호 Polyline, 지름 `h × 0.3` |
| 지시선 끝 ~ 글자 간격 | `h × 0.2` |
| 레이어 | 현재 레이어 |

---

## 3. 주의

- 생성물(지시선 Line · 점 Polyline · Text)은 **개별 엔티티** — 그룹·블럭·XData 없음. 지울 때 셋을 같이 선택해야 한다.
- 기울어진 Line 은 가로·세로 중 가까운 쪽 형상으로 그린다.
- 클릭 위치가 Line 위(지시선 길이 0)면 건너뛰고 다시 묻는다.
- `a` 300 미만·길이 조건 같은 필터는 없다 (사용자가 직접 고르므로).
